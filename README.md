# HW-03 — LifeSpot, урок 29.7

Проект LifeSpot дополнен для промежуточной сдачи задания урока 29.7.

Реализовано:

- главная страница LifeSpot с тремя городскими трансляциями;
- строка поиска;
- фильтрация трансляций по названию города без перезагрузки страницы;
- отдельная страница «О проекте» по адресу `/about`;
- добавление отзывов с именем, текстом и датой;
- отдельные JavaScript-файлы для главной страницы и страницы «О проекте»;
- адаптивное отображение.

В этой версии намеренно отсутствует функциональность следующего этапа:

- слайдер и его изображения из урока 31.4.

Запуск:

```text
dotnet run --project LifeSpot.csproj
```
